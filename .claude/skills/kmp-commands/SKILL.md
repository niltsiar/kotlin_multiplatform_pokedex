# KMP Commands

Essential CLI reference for KMP development.

## When to Use This Skill
Use this skill when you need to execute build, test, or maintenance commands. Triggers include: "command", "build", "test", "gradle", "validation", "commit".

## Related Skills
- **@kmp-gradle**: For Gradle configuration and convention plugins.

## NEVER
- **NEVER manually edit `CHANGELOG.md`**. It is auto-generated by `git cliff`.
- **NEVER run iOS builds for routine validation**. They take 5-10 minutes. Use the Primary Validation command instead.

## 1. Primary Validation (ALWAYS RUN FIRST)
Android build + ALL tests (fastest feedback: ~45 seconds).
```bash
./gradlew :composeApp:assembleDebug test --continue
```

## 2. Platform Commands
| Target | Command |
|--------|---------|
| Desktop/JVM | `./gradlew :composeApp:run` |
| Ktor Server | `./gradlew :server:run` |
| Android App | `./gradlew :composeApp:assembleDebug` |
| iOS (Rarely) | `./gradlew :shared:embedAndSignAppleFrameworkForXcode` |

## 3. Testing
| Type | Command |
|------|---------|
| Unit Tests | `./gradlew :composeApp:testDebugUnitTest` |
| Record Screenshots | `./gradlew recordRoborazziDebug` |
| Verify Screenshots | `./gradlew verifyRoborazziDebug` |
| Compare Screenshots| `./gradlew compareRoborazziDebug` |

## 4. Dependency Management
| Task | Command |
|------|---------|
| Check for updates | `./gradlew dependencyUpdates` |
| Refresh dependencies | `./gradlew --refresh-dependencies` |
| View dependency tree | `./gradlew :composeApp:dependencies` |
| Conflict check | `./gradlew :composeApp:dependencyInsight --dependency <name>` |

**Stability Rules**:
- Stable stays stable.
- Unstable can upgrade within same major.minor (e.g., `alpha01` -> `beta01`).
- Unstable can upgrade to ANY stable version.

## 5. Commits & Changelog
**Conventional Commits Format**: `type(scope): description`
- Types: `feat`, `fix`, `docs`, `test`, `build`, `refactor`, `chore`.

**Changelog Workflow**:
```bash
git cliff --dry-run          # Preview changes
git cliff -o CHANGELOG.md    # Regenerate file
```

## 6. iOS Build Policy
- **Routine validation**: BLOCKED (use Primary Validation).
- **Only execute when**:
  1. Explicitly requested by user.
  2. Testing iOS framework exports.
  3. Validating iOS-specific `expect/actual`.
  4. Working on SwiftUI integration.

**iOS Project Files**:
- `open iosApp/iosApp.xcodeproj` (SwiftUI Production)
- `open iosAppCompose/iosAppCompose.xcodeproj` (Compose Experimental)

## 7. Gradle Utilities
- **Structure**: `./gradlew projects`
- **Clean**: `./gradlew clean`
